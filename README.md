# Corso Claude Code serale · L'esercitazione del 2 novembre

Qui trovi il materiale per l'esercitazione sulle skill: crearne una, controllarne una che hai già, oppure costruire il tuo `STYLE.md`. Lo dai al tuo Claude e lui ti guida, un passo alla volta.

## Come lo scarichi (due minuti)

1. **Scarica lo ZIP.** In questa pagina premi il pulsante verde **Code** in alto a destra, poi **Download ZIP**. Il file finisce nei tuoi Download.
2. **Aprilo.** Sul Mac fai doppio clic sul file. Su Windows tasto destro e **Estrai tutto**.
3. **Mettilo nel tuo Secondo Cervello.** Trascina la cartella che hai estratto dentro `0-Inbox/` della tua cartella del pacchetto, quella che contiene `LEGGIMI.md`. Claude lavora solo lì dentro: una cartella lasciata nei Download non la vede.
4. **Fai partire la guida.** Nell'app di Claude apri una conversazione nuova nella cartella del tuo Secondo Cervello e scrivi:

> leggi ESERCITAZIONE e guidami

Claude ti chiede quale strada vuoi fare e ti accompagna.

Su Windows può capitare che dentro la cartella estratta ce ne sia un'altra con lo stesso nome: va bene così, Claude la trova lo stesso.

## Cosa c'è dentro

- **`ESERCITAZIONE.md`**: il punto di partenza, con le tre strade e la checklist per chi ha già una skill.
- **`Da usare con Claude/Controlla la tua skill.md`**: otto domande per capire se una skill è fatta bene, e le correzioni.
- **`Da usare con Claude/Crea il tuo stile di scrittura.md`**: la guida per il tuo `STYLE.md`.
- **`Traccia del feedback.md`**: cosa scrivermi per email quando hai finito, entro domenica 8 novembre.

Per leggere i file non devi installare niente: si aprono già formattati qui sul sito, basta cliccarci sopra.

## Cos'è GitHub, in due righe

È un sito dove si conservano e si condividono file e progetti: pensalo come un Google Drive pensato per i progetti. Per te oggi è solo il posto da cui scarichi il materiale. Lo incontrerai di nuovo, perché tante skill già pronte si scaricano proprio da qui.
